## Truly independent native sequence

Compile once P0; execute **only `reset/attached`** with actual configured
one and two ODE workers; preserve an exit code and full trace per run.
Rebuild original ownership source (with read-only instrumentation only)
and execute **exactly the same** `Node.saveState → Node.loadState`
fixture, again on one and two workers. **No E5-A body-delete arm is executed.**

Each of the four arms records its own native exit and strict primary oracle
status without aborting the next arm. The paired final gate refuses PASS unless
**all four** are native 0, original E5 oracles pass, original `WbSolid::reset`
entry/exit is directly traced, and the new independent assertions pass.

If P0 fails, original comparison **still executes**. If original fails,
the P0 native evidence is still preserved. The last gate is RED rather than
masking an incompatible behavior.

### E5-B exact checks

1. `target.loadState("e5_provenance")` called on the real Supervisor.
2. P0 `E5_reset_id_enter → P0_reset_M_acquired →
   E5_reset_engine → P0_unregister → P0_internal_free →
   P0_reset_M_released → E5_reset_id_exit`.
3. Each **live engine contact in the reset phase** is unregistered
   and internally destroyed once *during M*, before M unlock.
4. No engine contact remains in P0 registries at teardown; no unpaired M
   scope, ongoing worker task, recursive M or destruction during active worker
   is accepted by the original E5 oracle.
5. The original read-only probe `BC_original_reset_enter/exit` confirms
   actual passage through `WbSolid::reset(id)`.

### E5-C distinct live joint witnesses

- **Group-owned plugin contact:** allocated inside plugin's own
  `dJointGroupID`, initially attached to the real target body,
  remains allocated in the group (`dJointGroupGetCount==1`) through RESET
  while being detached from its body; freed via `dJointGroupEmpty`
  by the plugin at teardown, never dereferenced afterward.
- **Standalone plugin contact:** attached initially, passed to the native
  public `dJointDestroy` after detach. P0 stages public destroy until
  **after releasing nonrecursive M**. Original Webots directly uses
  its ordinary reset loop; the public-call and gate traces are compared.
  The stale plugin handle is never inspected after that operation.
- **Plugin-owned permanent AMotor:** remains physically attached across
  RESET, and is explicitly destroyed by the plugin at cleanup; a RESET
  path that accidentally destroys it is RED.
- Group / standalone / AMotor IDs are distinguished **only while all three
  are simultaneously live**. Raw addresses are never treated as temporal IDs.
- Mutated logs are **negative controls only**, not physical proof.
